# 임마누엘의 길 12 · 질문을 꺼내고 함께 답을 찾아가는 페이지

기획일: 2026-11-01 (한국 시간). 목사님 검토를 위한 TEST 반영안.

## 페이지의 역할

청년이 자신의 질문을 알아보고 말할 수 있도록 돕고, 교회가 경청과 설명, 필요한 변화의 책임을 함께 지는 대화의 입구를 만든다. 완결된 답변집이나 익명 질문 접수 시스템으로 소개하지 않는다.

목사님의 기존 개론 10개 문단과 순서, 사진, 손그림 강조, 기존 12과 교재·문항·답변 저장 경로를 그대로 둔다. 개론 뒤에 질문 탐색과 대화 준비 영역을 추가한다. 1–11번 주제의 본문·기능에는 변경이 없다.

## 실제 화면과 기능

1. 페이지 안내: 우리의 고백 / 내 질문 찾아보기 / 대화 준비하기 / 12과 성경공부의 네 진입 링크.
2. 기존 개론: 원문 전체를 펼쳐 둠.
3. 질문 탐색: 여섯 주제, 14개 질문. 주제 버튼으로 필터. 펼치면 첫 안내, 관련 성경과 문맥, 후속 질문, 대화 메모로 이동 버튼.
4. 경청의 약속: 판단을 서두르지 않기, 말씀과 관행 구분, 교회의 변화 책임, 다음 걸음 함께 정하기.
5. 대화 메모: 질문·상황·바라는 대화를 정리해 복사. 선택 질문을 불러올 수 있음. 개인 상담 요청과 기존 성경공부로 연결.
6. 조사 근거: 출처와 조사 대상·연도·한계를 접이식으로 공개.
7. 기존 12과 성경공부: 과정·쪽·문항 키 및 저장 API 변경 없음.

## 내용 검토의 초점

- 의심과 질문을 즉시 믿음 부족으로 단정하지 않으면서 말씀과 성령 안에서 분별하는 목사님의 취지가 드러나는가.
- 담배, 연애, 과학, 권위, 교회 이탈의 질문이 섣부른 허용·정죄의 목록으로 읽히지 않는가.
- 상처의 책임을 피해자에게 돌리거나, 용서를 이유로 해로운 상황에 머물게 하지 않는가.
- 교회도 듣고 설명하고 바꿀 책임이 있다는 약속을 공동체가 실제로 실천할 수 있는가.

## 개인정보·기능 경계

- 새 메모는 React 화면 상태에만 존재한다. 서버 전송, localStorage, 쿠키 저장, 분석 이벤트를 추가하지 않는다. 페이지 이탈·새로고침 전 직접 복사하도록 안내한다.
- 복사는 사용자 클릭 때만 실행한다. 클립보드 오류 때 직접 선택·복사할 수 있는 읽기 전용 대화문을 표시한다.
- 상담 요청 링크는 기존 `/services/counseling`으로 이동할 뿐, 작성한 내용을 URL이나 서버로 전달하지 않는다. 기존 상담은 이름·연락처가 필요한 별도 절차임을 표시한다.
- 익명 제출 기능, 답변 기한, 공식 질문 심의 절차, 새로운 비밀보장 약속을 만들지 않는다.
- 신규 DB·인증·환경변수·도메인·의존성 변경 없음. 기존 Vercel 빌드의 migrate/prebuild 스크립트는 변경하지 않음.
