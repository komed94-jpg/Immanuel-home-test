# 예배 페이지 시안 · 2026-11-01

## 승인된 범위

임마누엘 TEST 홈페이지의 두 번째 길 `/way/worship`에 적용한다. 기도 페이지에서 확정한 **기존 개론 먼저 → 성경공부 / 예배를 준비해요** 순서와 구어체 안내를 유지한다. 기존 개론과 교재의 본문·질문·답변 저장 방식은 수정하지 않는다.

첫 화면은 기존 제목·인용문·주제어와 ‘먼저 읽어 보세요’ 안내다. 기존 개론 전체가 펼쳐져 있고, 마지막에 두 선택을 둔다. 예배 준비에는 짧은 설명, 은혜·예배·삶을 연결하는 1회 애니메이션, 자신의 말로 기도하는 질문 하나를 둔다. 입력은 선택이다.

논문의 불확실한 표지를 적용해 감동의 유무나 강도를 신앙의 확정 기준으로 삼지 않는다. 하나님의 거룩하심과 선하심, 그리스도의 은혜, 성령의 도우심, 말씀에 대한 인격적 응답과 이웃 사랑을 일상 언어로 풀었다. 단계별 성취나 예배의 성공 점수, 자동적인 은혜 체험을 제시하지 않는다.

개인 기도 입력은 컴포넌트의 메모리에만 보관한다. 전송·영구 저장을 하지 않으며 사용자가 누를 때에만 복사한다. 성경공부와 준비를 오가도 내용을 보존한다. 기존 성경공부의 로그인·답변 저장 기능은 별개다.

`#worship-study`, `#study-content`, 유효한 `?page=worship-…` 진입에서는 교재가 열린다. `#worship-prepare`, `#worship-moment`는 예배 준비가 열린다. 두 영역은 숨겨도 유지하고, 이동 시 초점을 목적지로 옮긴다. 동작 줄이기 설정에서는 기존 공통 스타일에 따라 모든 애니메이션을 끈다.
