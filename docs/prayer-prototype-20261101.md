# 기도 페이지 시안 · 기존 12길 복원 기준

## 범위와 사용 경험

사용자 승인: 2026-11-01, 임마누엘의 길 12개 중 기도 페이지에 논문의 가르침을 적용하는 시안을 만들고 계속 피드백한다. 최근 슬라이드와 애니메이션 효과도 적용한다.

대상은 `komed94-jpg/Immanuel-home-test`의 `https://immanuel-home-test.vercel.app/way/prayer`이다. 이 TEST 프로젝트의 배포만 갱신한다.

큰 핵심 문장 → 짧은 공감과 복음 설명 → 은혜·기도·사랑의 연결 → 자신의 말로 기도하는 단순한 읽기 흐름이다. 논문 발표의 근거·과정·결과를 일상 언어로 풀어 구성했다. 회심 순서를 확정하거나 기도의 결과를 보장하는 도식으로 사용하지 않는다.

최근 발표 자료의 큰 문장, 금색 강조와 연결의 시각 언어를 적용했다. 밑줄은 1.5초, 연결은 약 1.3초, 점 강조는 최대 2.1초 안에 끝나며 반복하지 않는다. 화면에 들어온 때 한 번 실행한다. reduced-motion 설정에서는 애니메이션이 없고 모든 내용은 항상 읽을 수 있다.

입력은 선택이다. 기도문은 React 메모리 안에만 있고 서버·로컬스토리지·쿠키로 보내거나 저장하지 않는다. 복사는 클릭한 때만 실행하며 실패하면 입력을 선택해 직접 복사하도록 안내한다. 다른 11개 주제의 본문, 공통 개론의 손그림, 교재 문항·키·저장 API는 변경하지 않는다. 기존 기도 원문은 그대로 보존하고 아래에서 펼치며, 기존 성경공부도 펼쳐서 계속 사용할 수 있다. `?page=`와 `#study-content` 진입은 공부를 자동으로 펼친다.
